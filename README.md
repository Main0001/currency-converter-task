# Currency-converter
Бэккенд-приложение для помощи в конвертации валют. Является прослойкой между клиентским приложением и сторонними API, предоставляющими инфо о курсах валют. 

## Цель:
Сделать backend прослойку для получения данных о доступных валютах, а также о их курсах относительно выбранной валюты с использованием технологии cookie.

## Что делает приложение:

### Получает список доступных для конвертации валют

### Получает курсы относительно заданной валюты

### Создает пользователя

### Получает данные существующего пользователя

### Изменяет данные существующего пользователя

Данные хранятся в Firebase SDK, приложение имеет кеширование на уровне запросов (RAM) и кеширование в BD.

## Технологии:
* Node.js(LTS)
* Typescript
* NestJS
* Axios
* Swagger
* Firebase SDK

## Требования
* Node.js 18+ (LTS)
* Firebase проект с Firestore
* API ключ от [CurrencyAPI](https://currencyapi.com/)

## Использование

### Запуск приложения
1. `git clone <repository-url>`
2. `cd currency-converter-task`
3. `npm install`
4. `npm start`
